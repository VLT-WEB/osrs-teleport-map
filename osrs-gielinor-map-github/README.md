# OSRS Clue Compass & Fairy Ring Map

An unofficial interactive Old School RuneScape teleport map, including Clue Compass STASH menu keyboard shortcuts and fairy-ring codes.

## Publish with GitHub Pages

1. Create a **public** GitHub repository named `osrs-teleport-map`.
2. Upload `index.html` and `README.md` to the repository root and commit.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select **main** and **/(root)**, then **Save**.
6. Once deployed, open `https://YOUR-USERNAME.github.io/osrs-teleport-map/`.

## Notes

- Requires an internet connection for Leaflet and map tiles.
- Clue Compass keyboard shortcuts were transcribed from in-game screenshots supplied by the project owner.
- **Fairy-ring map markers are not all tile-verified**: some are approximate regional placements. Do not present every green marker as tile-accurate.
- Check all mapped positions and shortcuts before relying on them for speedrunning or clue routes.
- Unofficial fan project, not affiliated with Jagex.
- Map tiles are fetched from the Explv OSRS map tiles project. Check upstream licensing/attribution before broader distribution.
